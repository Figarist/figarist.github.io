학부모님께 가장 자주 받는 메시지 중 하나는 이렇습니다. *"아이가 Scratch를 꽤 오래 했고 정말 좋아해요. 이제 Python으로 넘어가도 될까요, 아니면 아직 이른가요?"*

저는 Scratch와 Python을 모두 1:1로 가르치고 있는데, 솔직한 답은 나이만으로는 결정할 수 없다는 것입니다. 이 글에서는 제가 살펴보는 준비 신호, 텍스트 코드로 넘어갈 때 실제로 달라지는 점, 그리고 수업에서 전환을 어떻게 진행하는지 설명하겠습니다.

아직 첫 분야를 고르는 중이라면 먼저 [자녀를 위한 코딩 분야 선택 가이드](https://sivochka.com/ko/blog/how-to-choose-programming-for-child/)를 읽어 보세요. 이 글은 블록에서 키보드로 입력하는 진짜 코드로 넘어가는 한 가지 순간에 집중합니다.

---

## Scratch는 Python에 비해 "그냥 장난감"일까요?

아닙니다. Scratch에는 변수, 반복, 조건, 이벤트, 좌표, 스프라이트 간 메시지(방송), 복제 같은 진짜 프로그래밍 개념이 들어 있습니다. 점수, 생명, 타이머가 있는 게임을 Scratch로 만든 아이는 이미 프로그래머처럼 생각하고 있습니다.

Scratch가 없애 주는 것은 *문법*뿐입니다. 블록은 철자를 틀릴 수 없고, 의미가 맞는 자리에만 끼워집니다. 그래서 어린 아이들에게 잘 맞습니다. 따라서 질문은 "어떤 언어가 더 좋은가"가 아니라 **"아이가 블록이 줄 수 있는 것을 넘어섰는가"**입니다.

---

## Scratch에서 Python으로 넘어가면 실제로 무엇이 달라질까요?

논리는 그대로입니다. 그 주변의 거의 모든 것이 바뀝니다. 학부모님께는 이렇게 설명드립니다.

| | Scratch | Python |
| :--- | :--- | :--- |
| **코드 작성 방식** | 블록을 끌어다 연결 | 키보드로 텍스트 입력 |
| **실수** | 블록은 맞는 자리에만 끼워짐 | 오타, 빠진 콜론, 잘못된 들여쓰기 하나로 프로그램이 오류 메시지와 함께 멈춤 |
| **아이가 보는 결과** | 스프라이트가 무대에서 바로 움직임 | 처음에는 콘솔의 텍스트나 거북이(Turtle) 그림, Minecraft로 배우면 3D 세계 |
| **실행 환경** | 웹 브라우저(컴퓨터 또는 태블릿) | Windows 또는 Mac 컴퓨터에 설치 |
| **기르는 능력** | 논리, 이벤트, 좌표 | 같은 논리에 더해 정확성, 오류 메시지 읽기, 함수로 코드 정리 |
| **대표적인 첫 프로젝트** | 애니메이션 이야기, 아케이드 게임 | 퀴즈, 텍스트 어드벤처, 거북이 그림, Minecraft에서 건축하는 스크립트 |

아이에게 가장 큰 변화는 기술적인 것이 아니라 감정적인 것입니다. Python은 실수를 하면 바로 알려 줍니다. 준비된 아이는 오류를 퍼즐로 보고, 준비되지 않은 아이는 실패로 받아들입니다.

---

## 아이가 Python을 배울 준비가 되었다는 신호는 무엇일까요?

수업에서 저는 나이보다 아이가 어떻게 작업하는지를 봅니다. 텍스트 코드를 시도해 볼 때라고 알려 주는 신호는 다음과 같습니다.

### 블록을 놓기 전에 먼저 계획하나요?
준비된 아이는 블록을 끌어오기 *전에* 스크립트가 무엇을 할지 말로 설명할 수 있습니다. "고양이가 사과에 닿으면 점수를 1 올리고 사과를 무작위 위치로 옮긴다"처럼요. 이런 계획 습관은 어떤 언어보다 중요합니다.

### Scratch 프로젝트가 커지고 복잡해졌나요?
긴 스크립트, 많은 변수, 다섯 번 복사한 같은 블록 묶음. 블록으로는 느리고 불편하다고 아이 스스로 느끼기 시작하면, 더 짧고 재사용할 수 있는 Python 코드는 부담이 아니라 해방이 됩니다.

### "진짜" 프로그램은 어떻게 작동하는지 묻나요?
"진짜 게임에서는 이걸 어떻게 만들어요?" 같은 질문은 Scratch 편집기를 넘어서는 호기심을 보여 줍니다.

### 키를 하나하나 찾지 않고 타이핑할 수 있나요?
타자를 능숙하게 칠 필요는 없습니다. 하지만 영문 자판에서 글자를 찾는 데 오래 걸리면, 수업 시간이 생각보다 입력에 쓰입니다. 집에서 조금만 자판 연습을 해도 생각보다 큰 도움이 됩니다.

### 작은 실패를 견딜 수 있나요?
오류 하나로 수업 내내 기분이 상하지 않는다면 Python을 시작하기 좋은 상태입니다.

**아직 조금 이르다는 신호:** Scratch에서 여전히 새로운 것을 발견하고 있고, 프로젝트가 짧고, 타이핑이 매우 느리거나, 오류에 금방 짜증을 냅니다. 전혀 문제가 아닙니다. Scratch에서 보낸 시간은 낭비가 아니며, 그곳에서 쌓은 논리는 그대로 Python으로 이어집니다.

---

## 보통 몇 살에 Scratch에서 Python으로 넘어갈까요?

대략적인 기준으로, 제 [Scratch 수업](https://sivochka.com/ko/tutoring/scratch/)은 만 6~10세, [Python 수업](https://sivochka.com/ko/tutoring/python/)은 만 9~17세를 대상으로 합니다. 이 고민은 대부분 두 과정이 겹치는 만 9~10세 무렵에 생깁니다.

반대의 경우도 있습니다. 만 10세 이상에 처음 시작하는 아이라면 꼭 Scratch부터 할 필요는 없습니다. Python은 읽기 쉬운 문법 덕분에 만 9~10세 무렵부터 첫 언어가 될 수 있고, 만 6~8세에게는 Scratch부터 시작하기를 권합니다.

---

## 수업에서는 Scratch에서 Python으로 어떻게 전환할까요?

저는 Python을 "처음부터 다시 시작"으로 다루지 않습니다. 아이는 이미 많은 것을 알고 있고, 제 역할은 그 지식이 새로운 형태를 갖게 되었음을 보여 주는 것입니다.

1. **익숙한 것을 다시 만듭니다.** 숫자 맞히기 게임이나 점수 카운터처럼 아이가 Scratch로 이미 만들어 본 아이디어를 Python으로 작성합니다. 논리는 알아볼 수 있고, 형태만 새롭습니다.
2. **블록을 코드 줄로 옮깁니다.** "초록 깃발을 클릭했을 때"는 프로그램의 시작이 되고, "10번 반복하기"는 `for` 반복문, "만약 … 라면"은 `if`, 변수 블록은 변수가 됩니다. 예를 들어 Scratch에서 익숙한 카운터를 Python으로 쓰면 이렇습니다.

    ```python
    score = 0
    for i in range(10):
        score = score + 1
    print(score)
    ```

3. **눈에 보이는 결과를 유지합니다.** Python의 Turtle 모듈은 화면에 도형을 그리는데, Scratch의 펜과 아주 비슷하게 느껴집니다. 아이는 텍스트만이 아니라 결과를 직접 봅니다.
4. **오류 메시지를 함께 읽는 법을 배웁니다.** 제가 대신 버그를 고치지 않고, 줄 번호를 찾고 메시지가 무엇을 말하는지 이해하는 방법을 보여 줍니다. 텍스트 코드를 쓰는 프로그래머에게 가장 중요한 습관입니다.
5. **코드를 짧게 유지합니다.** 처음 몇 주 동안은 프로그램이 짧고, 수업의 더 많은 시간을 입력보다 생각하는 데 씁니다.

### Minecraft가 Scratch와 Python 사이의 다리가 될 수 있을까요?
Minecraft를 좋아하는 아이라면 많은 경우 그렇습니다. [Minecraft로 배우는 Python](https://sivochka.com/ko/tutoring/minecraft/) 수업에서는 코드가 게임 세계에 직접 블록을 놓고 건물을 지어서, 결과가 계속 눈에 보이고 재미있습니다. Windows 또는 Mac 컴퓨터용 Minecraft Java Edition이 필요합니다. 이 방법론은 [마인크래프트와 파이썬으로 배우는 프로그래밍 기초](https://sivochka.com/ko/blog/minecraft-python/)에서 자세히 소개했습니다.

## Python을 시작한 첫 몇 주 동안 부모님은 무엇을 기대하면 될까요?

처음에는 결과가 Scratch보다 *덜 화려해 보일* 수 있습니다. 알록달록한 스프라이트가 있는 Scratch 게임이 Python 텍스트 퀴즈보다 완성도 높아 보이지만, 실제로는 퀴즈를 만들 때 훨씬 많이 생각해야 합니다. 이는 자연스러운 일입니다.

프로젝트의 겉모습으로 판단하기보다 아이에게 자신의 코드를 설명해 달라고 해 보세요. 자기 프로그램에서 변수나 반복문이 무슨 일을 하는지 말할 수 있다면 전환은 잘 진행되고 있는 것입니다.

## 자주 묻는 질문: Scratch와 Python

**Scratch를 건너뛰고 바로 Python으로 시작해도 되나요?**
네, 만 9~10세 무렵부터는 Python을 첫 언어로 시작할 수 있습니다. 만 6~8세에게는 Scratch부터 시작하기를 권합니다.

**Python을 하려면 고사양 컴퓨터가 필요한가요?**
아닙니다. Zoom 화면 공유가 되는 일반적인 Windows 또는 Mac 컴퓨터면 충분합니다. 태블릿은 Scratch에는 괜찮지만 Python 수업에는 맞지 않습니다. 전체 체크리스트는 [첫 온라인 수업 준비 가이드](https://sivochka.com/ko/blog/first-online-coding-lesson-for-kids/)에서 확인하세요.

**Scratch에서 Python으로 넘어가는 데 얼마나 걸리나요?**
아이마다 다르기 때문에 정해진 기간을 약속하지 않습니다. 첫 수업들을 마친 뒤 제가 본 것과 다음 단계를 솔직하게 말씀드리겠습니다.

**아이가 어려워하며 Scratch로 돌아가고 싶어 하면요?**
그럴 때는 속도를 늦추고, 코드를 더 짧게 하고, 눈에 보이는 과제를 늘립니다. 프로그래밍에 대한 흥미를 아예 잃는 것보다 잠시 돌아가는 편이 낫습니다.
